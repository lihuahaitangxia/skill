# 限流与调用频次

详见 [docs/SKILL-DESIGN.md](../../../docs/SKILL-DESIGN.md) 第 4 节。

| 策略 | 参数 |
|------|------|
| Token Bucket | 20 次/秒 |
| 批量告警 | ≤50 条/批，批间 2s |
| 429 退避 | 1→2→4→8 秒，最多 4 次 |
| 单告警 API | ≈5 次（资源 1 + 指标 3 + CMDB 1） |
| 超时 | 单告警 60s，批量 300s |

## 降级

- CMDB 不可用 → 云标签 fallback
- CMS 无数据 → 指标 `-`，感知「待确认」
- 无凭证 → Mock 模式
